# Ollie Rive project

- This project owns Ollie's vector artwork and animation. Do not edit `../nez-mascot`.
- RML and Rive CLI syntax must be checked with `rive docs` and `rive schema`; do not guess types or property keys.
- `tools/build_ollie.py` regenerates `runtime.rml` from the reference animation scaffold plus Ollie's artwork. Change the generator for visual edits, then regenerate.
- After changing the generator or RML, run `rive . --verify`, `rive inspect . --summary`, and render the affected moods to inspect them visually.
- Use `rive . --once` to export an unsigned local build. Do not use `rive push` for preview.
- The user requested an HTML playground. Maintain `playground/index.html` and its rendered-frame fallback alongside the Rive runtime preview.
- Current artwork source is `artwork/build_artwork.py`, based on `reference/ollie-front-master.png`. Keep the SVG/RML exports consistent and preserve reference canvas alignment.
- `python tools/build_kit.py` regenerates the complete review kit. Keep `web-pet` and `playground` excluded from Rive compilation.
- `tools/scaffold/` is Ollie's local snapshot of the animation scaffold; build changes must not require modifying Nez.
- `data/model.json` is the canonical View Model source; `data.rml` is generated by `tools/build_data.py`. Validate model/presets/features/speech and runtime bindings before export.
- `docs/rive-cli/` stores versioned CLI docs/schema. `tools/sync_cli_docs.py` refreshes it when the installed version changes and recreates `build/doc_*.txt` aliases.
- Preserve the seven mood enum IDs/order and the `Mascot`/`Default`/`Main` public contract unless the user requests an API change. Feature mappings marked `mood_only` do not imply that their props are animated.
