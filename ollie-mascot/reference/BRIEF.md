# Ollie visual brief

The latest user supplied Ollie turnaround and parts sheet in the conversation is the primary visual reference. Its front view defines the rig proportions. The older overview image in this folder provides additional palette and product context.

Ollie is a green chibi owl for planning, healthy finances, and wellness. Required features: large green eyes, cream heart-shaped facial mask and belly, green layered wings, orange beak and feet, a two-leaf sprout, and a mint leaf AI Core on the chest. The body is calm and supportive, with restrained motion.

Palette approximated from the overview swatches: `#14463A`, `#448C4D`, `#8DCA8E`, `#B5D7A4`, `#FAF2DB`, `#FDC255`. Mint glow: `#74F5D0`.

The front pose, seven moods, wing gesture, and sleep/wake use one shared 2D rig. Side/back views and the illustrated app scenes are visual direction only; this Rive artboard does not rotate to those views.
