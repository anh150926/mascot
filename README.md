# Ollie Mascot

Thư mục [ollie-mascot](ollie-mascot/) chứa toàn bộ nguồn artwork, rig Rive, dữ liệu, tài liệu và các bản xuất của Ollie.

- [Playground](ollie-mascot/playground/index.html): thử biểu cảm và chuyển động.
- [Trang đối chiếu](ollie-mascot/review.html): xem ảnh tham chiếu, vector và các frame kiểm tra.
- [Bản xuất Rive](ollie-mascot/dist/ollie.riv), [SVG](ollie-mascot/dist/ollie-front.svg) và [PNG](ollie-mascot/dist/ollie-front.png): tài nguyên dùng trong ứng dụng.
- [Hướng dẫn build](ollie-mascot/README.md): nguồn cần sửa và lệnh dựng lại.

Để dựng lại, chạy `python tools/build_kit.py` trong thư mục `ollie-mascot`. Với bản web trong `ollie-mascot/web-pet`, chạy `npm ci` trước khi dùng các lệnh trong `package.json`.
